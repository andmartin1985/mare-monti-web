# Mare e Monti — versione web dimostrativa

Apri l'app: https://andmartin1985.github.io/mare-monti-web/

Scarica l'app Android: https://andmartin1985.github.io/mare-monti-web/scarica/

- **iPhone**: aprila con Safari › Condividi › "Aggiungi alla schermata Home".
- **Android**: aprila con Chrome › menu ⋮ › "Installa app".

I dati restano sul telefono di chi la usa. Per provarla: Altro › Dati dimostrativi › Carica.

Contiene solo l'app compilata (versione 0.17.3).
